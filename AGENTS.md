# Repository Instructions

## Purpose

Maintain a vendor-neutral, human-controlled AI-native SDLC playbook and its three reference skills.

## Boundaries

- Preserve the order `intent.md` → `spec.md` → `plan.md`.
- Preserve explicit human approval at every stage.
- Do not make one skill advance into the next stage.
- Do not add implementation permissions to the planning skill.
- Keep assumptions, decisions, evidence, risks, and approvals distinguishable.
- Update documentation, templates, references, and evals together when behavior changes.

## Validation

Check Markdown links and code fences. Validate each skill's structure and run its relevant evals before merging behavioral changes. Review Mermaid blocks for syntax and readability.
